# Tashkent Expat Listings site

This repository is the live source of Louis Train's Tashkent Expat Listings. Google Sites embeds the pages in the repo root by URL, so anything pushed to `main` goes live within minutes.

Before changing listings, read `tools/METHOD.md`. It holds the audience rule (English or language-independent events only), the data sources, the build commands, the checks and the review/publish workflow. All listing data is in `tools/build.py`.
